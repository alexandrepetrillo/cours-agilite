# 🃏 Template — Cartes Planning Poker

> À imprimer sur du papier cartonné, découper, et distribuer un jeu par personne.
> Chaque jeu contient 13 cartes.

---

## Signification des cartes

| Carte | Signification |
|-------|--------------|
| **0** | Rien à faire, c'est déjà fait |
| **1/2** | Très très petit effort (quelques minutes) |
| **1** | Très petit effort |
| **2** | Petit effort |
| **3** | Effort modéré |
| **5** | Effort moyen |
| **8** | Gros effort |
| **13** | Très gros effort |
| **20** | Énorme effort (peut-être à découper) |
| **40** | Trop gros ! Il faut découper cette story |
| **100** | Beaucoup trop gros ! Ce n'est pas une story |
| **?** | Je ne sais pas / pas assez d'information |
| **☕** | J'ai besoin d'une pause ! |

## Règles du Planning Poker

1. Le **Product Owner** lit une User Story
2. L'équipe **discute** brièvement (2 min max)
3. Chaque personne choisit une carte **face cachée**
4. Au signal, tout le monde **retourne sa carte en même temps**
5. Si les cartes sont proches → on prend la valeur médiane
6. Si les cartes sont très différentes → les extrêmes expliquent leur raisonnement
7. On **revote** si nécessaire
8. **Consensus** → on note l'estimation sur la User Story

> 💡 **Astuce** : les nombres suivent la suite de Fibonacci car plus une tâche est grosse, plus l'incertitude est grande. On ne cherche pas la précision, mais un ordre de grandeur !
