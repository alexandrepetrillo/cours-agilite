# 📊 Grille d'Évaluation par Compétence — Module Agile

> **Évaluation formative** : basée sur l'observation pendant les ateliers et jeux.
> Le formateur complète cette grille pour chaque étudiant au fil de la formation (½ journée + 1 journée).

---

## Mode d'emploi

- **Évaluer chaque critère** de 0 à 3 :
  - **0** = Non observé / Non acquis
  - **1** = En cours d'acquisition (participe peu, compréhension partielle)
  - **2** = Acquis (participe activement, bonne compréhension)
  - **3** = Maîtrisé (excellente compréhension, aide les autres, propose des améliorations)

- L'évaluation se fait **pendant les activités**, pas sur un examen final.
